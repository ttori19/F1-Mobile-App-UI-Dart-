# F1 UI Design 🏎️

## **¿Qué es?**
Diseño de la interfaz de usuario de una aplicación para móviles totalmente interactiva. Este proyecto simula una posible aplicación oficial de la **FIA** para el seguimiento del mundial, incluyendo pilotos, equipos e históricos. 

En esta primera versión, se incluye el seguimiento detallado de los pilotos. Cabe destacar que es una **maqueta inicial** diseñada para demostrar las capacidades de desarrollo de aplicaciones multiplataforma con **Flutter** y el lenguaje **Dart**.

---

## **🛠️ Tecnologías**
Para este proyecto es necesario contar con:
* **Flutter SDK**
* **Lenguaje Dart**
* **IDE Recomendado:** Visual Studio Code o Android Studio con las extensiones oficiales de Flutter/Dart.
